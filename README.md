# VIN Decoder

SPA application for decoding vehicle VIN numbers using the NHTSA API.

## Features

- Decode VIN
- VIN validation
- Display decoded vehicle information
- Last 3 search history
- LocalStorage support
- Variables list
- Variable details page
- Responsive layout

## Technologies

- React
- React Router
- React Hook Form
- SCSS
- Fetch API

## API

https://vpic.nhtsa.dot.gov/api/

## Run locally

```bash
npm install
npm run dev
```
